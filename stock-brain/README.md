# 量化智库 · 知识大脑模拟交易系统(stock-brain)

用你自己积累的股市知识（直播转写稿、历史交易复盘、笔记方法论）作为 AI 大脑的知识底座，并让策略不断自我进化：

```
知识入库 → AI 蒸馏规则卡(自动标注风格:短线/波段/中线/长线)
   ↓ 按风格选知识子集 + 设参数
创建策略 ──一策略一账户──→ 独立模拟账户运行(每笔交易附完整思考动机)
   ↓ 1/5/20日结算归因 → 知识胜率 + 策略胜率
AI 生成进化提案(换知识/调参数/新策略) → 你批准 → 新一代策略试跑 → 优胜劣汰
   ↑__________________________________________|
```

- **知识自写**：除了蒸馏你的材料，AI 每日收盘后写盘面小结、每周反思知识库自身，全部走"草稿→验证→激活/退役"生命周期
- **策略场**：知识子集 + 风格约束 + 参数 = 策略，一策略一独立账户（100 万模拟资金），总览按策略排行
- **交易动机**：每笔决策呈现 大盘判断 / 构思 / 执行计划 / 认错条件 四段结构，引用的知识以 #KB 编号标注
- **实盘接口**：PaperBrokerAdapter 已实现；LIVE 适配器留有接口位，`BRAIN_ALLOW_LIVE=true` + 券商适配验收前，实盘下单一律拒绝

## 快速开始

要求 Node.js 22+（`node:sqlite` 内置依赖）。

**日常使用**：双击项目根目录的 `start-brain.bat` 即可——它会自动启动服务（已在运行则跳过）并打开浏览器访问 `http://127.0.0.1:8787`。服务跑在一个最小化窗口里，关掉那个窗口即停止应用。

**开发模式**（改代码时用）：

```bash
npm install
cp .env.example .env      # 填入你的 DeepSeek API Key（也可稍后在界面里配置）
npm run dev               # 同时启动 API(127.0.0.1:8787) 和前端(5174)
```

首次打开 `http://127.0.0.1:8787`（开发时用 Vite 地址 `http://localhost:5174`），本地单机无登录，推荐流程：

1. **系统设置** → 配置模型 API Key
2. **知识库** → 导入你的转写稿/笔记目录 → 点「AI 蒸馏规则」生成带风格标签的规则卡
3. **策略场** → 创建策略（选风格 → AI 推荐知识子集 → 设参数）→ 立即运行或等调度器自动跑
4. **投资总览** → 查看决策（展开看思考动机）、策略排行
5. 策略积累结算数据后，在策略场点「请求 AI 进化提案」→ 审批 → 新一代自动试跑

## 知识材料格式

- **直播转写**（`导入转写`）：目录下的 `.md` / `.txt`。兼容 live-transcribe 的 Whisper 输出格式（自动剥离头部元信息），口语长文自动按句子分块
- **笔记方法论**（`导入笔记`）：目录下递归扫描 `.md` / `.txt`
- **交易复盘**（命令行）：CSV，需含列 `日期,代码,复盘`（可选 `名称,方向,价格,数量`）：

```bash
npm run ingest:trades -- --file path/to/trades.csv   # 或直接调用脚本传 file 参数
```

导入后点「AI 蒸馏规则」，LLM 把口语内容蒸馏成结构化规则卡（主张/入场条件/出场条件/风险提示/置信度）。没有配置 API Key 时也可以先入库，蒸馏会等 Key 配置后由调度器自动补做。

## 策略类量化链路(自上而下)

```
数据地基:每日收盘自动采集候选池日K + 两市成交额 + 涨跌家数 → 本地行情仓库(sb_daily_bars)
   ↓
宏观(环境判定书):量能档位(1.5-2万亿防守/2-3万亿均衡/3万亿+进攻) + 市场宽度
  + 赚钱效应两层验证(高位/中位票次日盈利滚动跟踪) → 风险预算,自动缩放各策略仓位
   ↓
中观(行业强度榜):候选池按行业聚合涨跌,强势/弱势行业 → 注入决策
   ↓
微观(策略执行):知识子集 + 风格纪律 + 风控(回撤熔断/行业集中度/连败降仓)
   ↓
验证与进化:1/5/20日归因 + 回放回测(D日信号→次日开盘成交,防未来函数)
  → 进化提案先过回测参考 → 新一代策略试跑
```

## 与 DeepSeek Harness 协作(人机共研)

本系统对外部代理提供标准接口,完整文档见项目根目录 **`AGENTS.md`**:

```
直播转写完成(BRAIN_TRANSCRIPT_DIR 自动监控)
   → 自动入库(kind=transcript, pending)并触发 AI 蒸馏
   → 你与 DeepSeek Harness 阅读转写/镜像,共同探讨
   → Harness 把确认后的结论写入「知识收件箱」(data/knowledge-inbox/,带前置元数据的 md)
   → 调度器约 1 分钟内自动入库(人审知识直接 active),文件归档到 processed/
```

- **收件箱协议**:`kind/styles/symbols/tags/confidence/claim/entry_conditions...` 前置元数据,有 `claim` 即按规则卡入库;模板在 `data/knowledge-inbox/_知识模板.md`
- **知识镜像**(供代理快速读取):`data/exports/knowledge.json`(全量结构化)、`knowledge.md`(按类型分组的可读版)、`strategies.json`(策略清单);调度器约 20 分钟刷新,或 `GET /api/export/knowledge.json|md` 即时刷新
- 你的桌面文档(`股市知识库.docx`、`自己的模式.docx`)已转换为收件箱格式并入库存档

## 自动调度

服务启动后内置调度器（每分钟心跳），采用"慢思考 + 快执行"两层架构：

**执行层（快，每分钟，零 AI 成本）**
- 止损线：跌破立即强平
- 止盈线：到达立即兑现（AI 决策时给出）
- 关键位破位：AI 在决策时挂出 2-4 个关键价位，跌破/突破立即唤醒 AI 复核（一次性）
- 盘中异动：滚动 5 分钟窗口内涨跌超 3%，不等策略节奏立即唤醒 AI 复核（同账户 10 分钟冷却）
- 触发后即时复盘：任意条件触发（止损/止盈/破位/异动）后插入一次独立的 AI 思考——评估环境变化、剩余持仓联动、资金再部署还是持币（带触发上下文注入，不占常规节奏，同账户 10 分钟冷却，批量触发只复盘一次）

**策略层（慢，按策略风格）**
- 自动运行节奏：短线每 30 分钟、波段每小时、中线/长线每日一次
- 每日：结算到期决策的 1/5/20 日结果，归因到知识与策略并更新知识生命周期
- 周六：LLM 周反思，从近期成败提炼新经验
- 周日：AI 生成策略进化提案（等你在策略场批准）
- 随时：后台自动蒸馏新入库的知识

触发记录在「投资总览 → 盘中触发记录」可见。

## 安全边界

- 当前为纯模拟盘（PAPER），不接入真实资金；实盘需要单独的券商适配与对账验收，代码中保留了适配边界的设计位
- 本地单机设计，无登录体系，请勿直接暴露到公网；如需远程访问请自行加 HTTPS 反向代理与访问控制
- AI API Key 在库中 AES-256-GCM 加密存储
- 系统仅限本机/内网使用，公网部署请务必套 HTTPS 反向代理
