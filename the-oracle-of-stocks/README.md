# 股神：个人 A 股量化研究与模拟交易系统

这是一个面向个人部署的单机量化系统。当前目标不是机构级交易平台，而是持续提升选股、研究、可信回测、交易计划和风险控制能力。

## 当前保留范围

- A 股行情、交易日历、基本面和数据质量检查
- 多模型研究、决策记录和结果归因
- 可复现回测、walk-forward 验证和回测任务
- 个人交易计划：买入区间、目标仓位、止损、分档止盈和建议股数
- 模拟交易、账户、持仓、现金账本和公司行为
- 组合风险、集中度和压力测试
- 单用户部署、登录、SQLite 数据库、普通备份和完整性检查
- 将来接入真实券商所需的最小适配边界

## 已删除的方向

项目不再包含 PostgreSQL shadow/cutover、KMS/HSM 离线签名仪式、Kubernetes 部署样例、容量认证、部署准入/排空、主备切换、灾备演练、复杂生产配置基线、多人 LIVE 审批和外部实盘订单认领入口。

旧数据库中的历史表暂时保留，避免升级时破坏已有数据；它们不再有 API、脚本或运行时入口。

## 安全边界

- 默认使用 PAPER 模式。
- 当前券商提交路径只允许 SANDBOX 适配器。
- LIVE 写入和真实资金接入继续关闭。
- 个人交易计划只生成建议，不自动提交订单。
- 在接入真实账户前，必须单独完成券商适配、对账、撤单恢复、限额和小资金验收。

## 本地运行

要求 Node.js 22 或更高版本。

```bash
npm install
npm run dev
```

默认访问：

- Web：Vite 输出的本地地址
- API：`http://127.0.0.1:8787`

生产式单机启动：

```bash
npm run build
npm start
```

## 个人服务器建议

- 最低：2 核 CPU、4 GB 内存、20 GB SSD
- 推荐：4 核 CPU、8 GB 内存、50 GB 以上 SSD
- 大规模回测主要消耗 CPU、内存和磁盘；日常行情、选股与模拟交易不需要高性能服务器
- SQLite 数据库和回测制品目录应放在本地 SSD，并定期备份到另一块磁盘或对象存储
- 远程访问应放在 HTTPS 反向代理后，不应直接暴露无 TLS 的服务端口

## 配置

复制 `.env.example` 后按需修改。最小本机部署只需要数据库路径和 AI 模型配置；其余项都有安全默认值。

AI 配置也可以在系统设置页面保存。环境变量 `OPENAI_API_KEY`、`OPENAI_BASE_URL` 和 `OPENAI_MODEL` 可作为默认值。
